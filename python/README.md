# Native DeepSeek Harness RSI worker

This Python package invokes the authors' exact `IndustrialEfficiencyController` for TRAIN, protected validation and freeze, with `official_deepseek_harness_sdk` execution identity and `prompt_suffix` application. The upstream controller lives in a module named `codex_chisel`, but no Codex executable, installation or runtime is used. A qualified call to the original base controller's `evaluate_test` implements paired evaluation on a fresh local corpus: the successor's prohibition against reopening its authors' historical TEST remains unchanged upstream. The CLI rejects non-`local-` corpus names as an accidental-reuse guard; callers must not relabel historical data to bypass it.

The native `sdk_worker.mjs` uses the installed official DSH `DeepSeekHarness` SDK, profile composition and tools. It runs one fresh SDK session per callback. The normal shared DSH home provides the existing credential service; the separate `harnessmm-training` profile and explicitly fresh sessions isolate the experiment from personal conversation history. No credentials are copied or logged by this adapter. Every task has a fresh temporary working directory; the adapter never opens personal sessions or projects. An explicit alternative home may be supplied.

Native launch uses the captured development launcher path (override it with `--dsh-bin`) by default. Provider and model are required caller choices; the extension passes the current session's exact route. Reasoning effort is optional and omitted from SDK initialization unless explicitly selected. No provider or model is hardcoded. Provider routing and credentials must already be registered by the selected profile; initialization rejects unsupported routes. Baseline/optimizer children receive `DSH_HARNESSMM_ENABLED=0`; candidate children receive `1`; all receive `DSH_HARNESSMM_NO_POLICY=1` to prevent deployed policy recursion while the authors' rendered instruction is tested. Candidate graph + instruction is a combined intervention, so the result is not an instruction-only causal measurement.

The worker emits native session notifications as NDJSON and a terminal receipt. Exact accounting comes from native `deriveTurnTokenUsage` over every observed complete root and descendant turn, including its retry semantics. Native input is uncached: author input is `native totalTokens - native outputTokens`, including native cache-read and cache-write buckets once. Missing or contradictory lifecycle evidence makes complete usage unknown. Native monetary prices remain unknown. Partial output survives worker timeout and process-group termination. No sampling seed guarantee is claimed. SDK client, native meter, worker, DSH launcher, local callback, scorer/corpus and authors' modules are source sealed.

The scorer runs trusted `verifier_argv` only after actor exit. Its contents are not copied into the actor workspace, prompt or SDK arguments; the optimizer receives the actor's available trajectory and verifier PASS/FAIL only. The verifier itself executes with the user's privileges, outside a security container. Use only trusted corpora and actors, or add external isolation. Workspace separation is not a security sandbox.

Run from a Python environment with the pinned upstream `phiagent` package installed or on `PYTHONPATH`:

```bash
PYTHONPATH=/absolute/dsh-harnessmm/python:/absolute/HarnessMM \
  python -m dsh_harnessmm_rsi train \
    --corpus /absolute/dsh-harnessmm/corpora/synthetic-python-v1.json \
    --output /absolute/new-run \
    --dsh-home /absolute/path/to/dsh-home \
    --profile harnessmm-training --provider YOUR_PROVIDER --model YOUR_MODEL --iterations 1
```

Only `train` makes model requests. `doctor` verifies pinned author sources; `inspect PATH` displays a report; `export POLICY --output FILE` exports human-readable instructions and hashes. `route --policy PATH` reads a public task from stdin, verifies exact frozen policy/source seals, and prints JSON containing the authors' routing decision, `instruction`, policy/source/file/prompt hashes and application. Empty instruction means abstention or baseline. The DSH extension should inject only the selected nonempty instruction. Unconditional application of exported instructions bypasses learned routing.

Package the complete `python/` directory: `sdk_worker.mjs` is a sibling of the Python package. SDK and meter module paths default to the installed DSH source checkout and can be overridden with `--sdk-module` / `--meter-module`; `--node`, `--dsh-bin`, `--profile`, `--sdk-patch`, `--provider`, `--model`, `--timeout` and `--dsh-home` are configurable. No global configuration is edited.

Corpus JSON schema is `dsh-harnessmm-corpus/v1`, a `name` beginning `local-`, and a `tasks` array. Each task has unique `id`, independent family `unit_id`, `public_prompt`, `seed_files` mapping relative paths to text, and `verifier_argv` as a nonempty command argument list. Paths cannot escape the workspace. At least 20 independent units divisible by five are required. All variants/repetitions of a family share a unit ID. Authors' partition builder assigns 20/20/60 by frozen seed `20260928`; the bundled 20 synthetic Python exercises split 4/4/12. This small synthetic corpus is a smoke population, not an independent scientific benchmark.

Outputs: `run.json`, `episodes/*.json`, `train-report.json`, `validation-report.json`, frozen `policy.json` before TEST, final `report.json`, and `learned-instructions.md` plus hash manifest. Failed and malformed calls retain measured usage. Empty final instructions are valid when no candidate passes unchanged author admission and validation gates. Tests use mock model callbacks; their passing status does not establish benchmark gains.

Policy execution identity records exact provider, model, requested reasoning effort (`provider-default` marks omission), SDK profile, native tools contract and source-contract SHA-256. `run.json` and route-helper output expose `activation_route` with omitted effort normalized to null, and `cross_route_transfer_validated=false`. Runtime activation must match provider/model/effort and verify its source/tools contract; learned instructions must not transfer silently to other routes. `--reasoning-effort EFFORT` forwards a selected effort, while omission preserves provider defaults.

Runtime deployment must append the route helper's **`prompt_suffix`** to the original public prompt. This is the exact byte suffix rendered by the authors' frozen policy, including its delimiter. The separate `instruction` field is for inspection and must not be substituted into a system section.

Cancellation handlers cover SIGTERM and SIGINT during the lifecycle. The Python owner terminates and drains the worker process group, allowing native SDK `harness.close()` cleanup before escalation; cancellation prevents subsequent episodes. Real process-tree regression checks that both worker and grandchild stop after parent SIGTERM. Native notification metering reads the SDK's `params` envelope, verified against the installed SDK serialization and native token-meter fixtures.

Source contracts cover SDK/meter/worker helpers, extension `index.mjs`, `controller.mjs`, `jobs.mjs`, package/patch files and vendor sources, plus top-level training profile configuration files. `DSH_HARNESSMM_EXTENSION_ROOT` can override the inferred extension root. These path/hash commitments are included in frozen execution identity and checked before every callback and when routing a deployed policy; changes fail closed. Runtime/session persistence is intentionally excluded from the configuration contract.

Every actor and optimizer callback receives a distinct `DSH_HARNESSMM_DATA_DIRECTORY` at `episodes/extension-data/<request_id>`, outside its temporary task workspace. Training children therefore keep their graph statistics, audit logs and improvement-job state separate from the desktop extension and from each other. Runtime state directories are excluded from source contracts.

Native integration tests also load the **installed package by name** through an isolated SDK profile's bundle manifest. The test uses an individual `node_modules/@local/dsh-harnessmm` symlink to the installed package so native linked-root discovery supplies peer fallback correctly; symlinking the entire `node_modules` directory does not establish that linked-root ownership. Both arbitrary provider fixtures execute `root -> A -> B` with two original adapter calls and two certified substitutions. A native denied-A case executes only root and produces no substitution certificate. These fixtures make no network/provider calls and use explicit synthetic request counters.
