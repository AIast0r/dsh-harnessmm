# Distribution and provenance

This is the source and clean publication build of `@local/dsh-harnessmm` **0.1.4** from my DeepSeek Harness setup. JavaScript/Python runtime code, corpus, upstream lock, package manifest, and bundle configuration are unchanged from the locally verified edition. Public-facing documentation adds installation, compatibility, and provenance details.

HarnessMM upstream is [YuhuaJiang2002/HarnessMM](https://github.com/YuhuaJiang2002/HarnessMM), revision `c8f19947e59feaa8103c05155bd79ef3eb084730`, under Apache-2.0. The vendored controller and Python author modules are retained unmodified with licenses and notices. Native DSH integration, authenticated tool receipts, SDK callbacks, background management, and packaging are additions.

The public source and release omit Python bytecode, test caches, generated fixture receipts, local environments, credentials, provider configuration, personal conversations, workspaces, deployed learned policies, and runtime/job state. These omissions do not remove runtime source. The synthetic coding corpus is included.

This package has narrow native DSH compatibility (`>=0.2.1-rc.2 <0.2.2`). Self-improvement requires a separately configured native SDK profile and matching DSH source/build paths. The captured runtime’s development-path fallbacks and native integration-test paths remain in source; configure the documented overrides on another machine.

The 37 keyless tests passed before publication. Native fixtures use the maintainer’s DSH SDK checkout and installed package. They do not prove provider entitlements, benchmark quality, or real token savings. No live optimization campaign ran as part of publication.
